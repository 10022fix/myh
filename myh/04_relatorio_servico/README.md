# Relatório de alunos com serviço

**Aluno:** Pedro Henrique Ferreira Gonçalves  
**Número:** N24  
**Turma:** 3 INFOD

Aplicação Angular que consulta o serviço HTTPS de listagem e apresenta os alunos cadastrados com ID, RA, nome, turma, sala e período. Cada registro mostra os botões **Editar** e **Excluir**; conforme solicitado, eles são apenas botões de interface, sem rotas ou ações implementadas.

O serviço também contém o endereço HTTPS de cadastro e um método para enviar os dados.

## Executar

1. Abra um terminal nesta pasta.
2. Execute `npm install`.
3. Execute `npm start`.
4. Abra o endereço mostrado pelo Angular CLI (normalmente `http://localhost:4200`).
